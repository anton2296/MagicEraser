My small pet project that ultimately didn’t make it to the App Store, due to the fact that a similar functionality appeared in the system by default.

This app was created to replace unwanted objects in a photo with a placeholder generated by a neural network.
There is also an uncrop feature; using the same neural network, you can expand the image.

How it works:
The work is based on a simplified version of LaMa; any processing involves a loop in which we move an overlapping window of a certain size (corresponding to the resolution capacity of LaMa) over the image mask selected by the user, and based on the mask, we replace the image with a generated placeholder. Each subsequent window is overlapped to avoid unwanted artifacts.
